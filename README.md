
## 🌐 Deploying to the Web (Free & Instant)

### Option 1: GitHub Pages
1. Initialize git in this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Oseni Quadri portfolio website"
   ```
2. Create a repository on GitHub (e.g., `oseni-quadri-portfolio`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/oseni-quadri-portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub repository settings, navigate to **Pages** -> Source: `main` branch `/root` -> Save. Your site will be live at `https://YOUR_USERNAME.github.io/oseni-quadri-portfolio`.

### Option 2: Netlify / Vercel
- Simply drag and drop the `quady-animator-portfolio` folder directly into Netlify Drop or import your GitHub repository into Vercel with zero configuration required.
